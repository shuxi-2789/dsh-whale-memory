# 旧记忆搬家指南（已有几个月聊天记录 → 装本系统）

> 适用人群：你和你的 AI 已经聊了很久，现在想给她装上这副"长期大脑"，
> 担心过去白聊了。先说结论：**过去不会自动进来，但值得进来的都能搬。**

## 先选路线（三选一）

| 路线 | 适合谁 | 成本 |
|---|---|---|
| **A · 从零开始**（默认，推荐大多数人） | 能接受"她从今天起记事"，过去留在聊天软件里就好 | 10 分钟 |
| **B · 蒸馏回填**（本指南主体） | 过去里有身份级的事（怎么认识的、重要约定、长期偏好），想让新大脑接上 | 1–3 小时，可分批 |
| **C · 全文灌入** | ❌ 不推荐，理由见文末 | — |

---

## 路线 A：从零开始

1. 按 README 装好插件，跑 `whale_doctor` 到全绿。
2. 填 `根记忆·总卷.txt` 里的「记忆的开始」段——**这里可以写你们的过去**：
   认识日期、她叫什么、你叫什么、记得的第一件事。三五句就够，这是身份锚点，永不截断。
3. 完事。之后的日记/周记/备忘录会自然攒出新记忆。

## 路线 B：蒸馏回填（存量记忆 → 大脑文件）

**核心原则：大脑不是聊天记录仓库，是"值得记住的事"的档案。**
搬的是结论和事实，不是原话。

### 第 1 步 · 找到旧记录

- DSH 用户：会话存在 `%USERPROFILE%\.dsh\profiles\<profile>\` 下（sessions 数据）；
- 其他宿主：导出聊天记录（JSON/TXT/Markdown 均可）。
- 建议按会话/按周切成小块，**一次只处理一块**（10MB 一口吞会把蒸馏 AI 也撑爆）。

### 第 2 步 · 蒸馏（让本地 AI 读旧聊天，产出"值得记的事"）

把下面这段提示词连同旧记录一起交给你的 AI（**在你自己机器上跑，不要把旧聊天上传到任何云端服务**）：

```text
读这份聊天记录，只提炼以下五类内容，其余全部丢弃：
1. 身份级事实：双方怎么称呼、关系、认识的时间地点、重要约定
2. 长期偏好：对方反复表现出喜欢/讨厌的东西（吃穿住行、话题、边界）
3. 进行中的事：还没办完的话题、承诺、悬着的问题
4. 情感节点：吵架、和解、大好消息、低谷陪伴（一事一段，写事实不写原话）
5. 关于"我"（AI）的设定：对方希望我叫什么、什么性格、什么不能做

每条输出格式：
〔YYYY-MM-DD〕一段话（≤80 字，第三人称可核对的事实句，不要"我们聊得很开心"这种空话）
```

### 第 3 步 · 人工过目（不可跳过）

蒸馏稿里一定混着**不该进大脑的东西**：对方的真实姓名/住址/手机号、你的其他社交账号、
一次性闲聊被误判成"长期偏好"。**逐条删改后再落盘**——大脑文件会被每轮注入，
写进去的每个字她都会当成事实认领。

### 第 4 步 · 落盘（只用追加，放对楼层）

| 内容 | 写进哪 |
|---|---|
| 最近三个月的事 | `临时文件夹/<当前归档>/备忘录.txt`（追加段落） |
| 身份级事实、长期偏好 | `根文件夹/根记忆·总卷.txt` 对应小节（追加） |
| 更早的、按时间段成套的 | `根文件夹/时代卷/周记存档.txt`（按周归并） |
| 关于对方的稳定印象 | 可选：`记忆回溯模块.md` 的码本先补关键词，再打〔标签〕 |

⚠️ 红线照旧：**只追加、不改写已有正文**；手改文件前先复制一份 `.bak`；
梦和闲聊都不进事实层。

### 第 5 步 · 重建索引 + 验收

```
whale_index                 # 让新段落进索引卷
whale_tags {mode:"dry"}     # 看哪些新段落缺〔标签〕
whale_doctor                # 全绿
whale_recall {message:"<你们之间一个只有旧聊天里才有的词>"}
                            # 抽查 5 个，命中 ≥4 即合格
```

命中不了多半是阈值问题（旧聊天用词密度和你原本调参的大脑不同），
跑 `node vendor/brain/scripts/probe-simhash.mjs "抽查句"` 看距离分布再调 `config.json`。

## 路线 C 为什么不做

把原始聊天全文灌进大脑文件，等于让她的"记忆"里 90% 是"在吗/哈哈/晚安"：
- 快照预算会被水话吃光，真正重要的身份段反而被挤出去；
- 四层召回的 n-gram 层会被高频闲聊词淹没，召回质量断崖下跌；
- 原话里的他人隐私（她提到的朋友、同事、家人）会不加过滤地进入每轮注入——这正是红线体系要防的事。

**要留原文，留在聊天软件里；大脑只存"值得记的事"。**

## 常见问题

**Q：搬完之后她能"想起"旧事吗？**
A：能想起你蒸馏进大脑的部分。没写进去的等于没发生——这是设计，不是缺陷。

**Q：能搬一半试试吗？**
A：能，而且建议如此。先搬最近一个月，用两周，看召回质量再决定搬更早的。

**Q：蒸馏要花钱/要联网吗？**
A：用你宿主现成的模型就行（本地/已有订阅），全程不需要把记录发给第三方。
